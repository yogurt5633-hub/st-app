# Тавернка

Рабочая ветка пользователя — `tavernka-gpt`. Все доработки, проверки и тестовые сборки выполняются здесь. `main` содержит опубликованную версию. Исходная версия для возврата сохранена в `backup/main-before-tavernka-2026-11-14`. Перед изменением `main`, слиянием или публикацией стабильного релиза нужно отдельное прямое указание пользователя.

Исходный коммит `main` — `b1f112058f0a4285044e0a464e2ccd112ab217f7`.

Требования и состояние работы находятся в `docs/work/tavernka-progress.md`. Дизайн следует `docs/work/design-direction.md` и unslop Damir Sokolovsky, https://github.com/heydamir/unslop, CC BY 4.0.

Проверки после изменений — `npm test`, `npm run test:browser`, сборка Android APK. Успешные проверки сами по себе не означают выполнения всех требований. В отчёте перечислять оставшиеся задачи и ограничения проверок.
