## Проверки и оставшиеся ограничения

- Модульные тесты запускаются через `npm test`, браузерные через `npm run test:browser`.
- На коммите `7df728418210c439d7cb4b2a49c4579c069d3223` прошли 87 модульных тестов и браузерная проверка пяти тем на ширинах 320/390 px, каталога, настроек, ручного перевода и офлайн-кэша.
- APK этого коммита успешно собран в [GitHub Actions #43635563367](https://github.com/yogurt5633-hub/st-app/actions/runs/43635563367). Публикация стабильного релиза пропущена.
- GitHub Actions для `tavernka-gpt` выполняет обе проверки, сохраняет снимки пяти тем на мобильных экранах и собирает APK.
- Браузерные проверки выполнены локально в Chromium с разрешением на тестовый HTTP-сервер и повторяются в GitHub Actions.
- Проверка на физических телефонах, особенно слабых и старых моделях, остаётся обязательной для подтверждения поведения на этих устройствах.
- Push-сервис, его адрес и настройки доставки в проекте отсутствуют. Периодическую проверку обновлений нельзя считать мгновенной доставкой.
- Тестовые APK устанавливаются вручную. Встроенный источник APK остаётся каналом стабильных релизов. Канал исходников выбирается при сборке: `tavernka-gpt` для тестового APK, `main` для обычного.
- Автодетект предлагает повторяющиеся слова по локальным правилам. Пользователь проверяет предложения и указывает перевод.
- Внешние переводчики и реальные подключения к моделям зависят от сервиса и ключей пользователя.

## Следующее обновление: маскот и каталог, 0.4.28

По следующей просьбе пользователя убрана подложка маскота на главной, в знакомстве и во всех пустых состояниях веб-приложения. PNG уже были прозрачными; изменены общие стили, образ персонажа сохранён. Удалён отдельный блок проверки «Подключение к модели» с главной, из «Ещё» и настроек. Настройки общения с моделью в самой SillyTavern остаются рабочими.

В админке по удержанию заголовка каталога добавлена публикация расширений. Пользователь выбрал оба способа: ZIP с телефона и ссылка на публичный репозиторий GitHub. ZIP проверяется до записи файлов: пути, manifest.json, файлы входа, CRC, размер и типы записей. Установка создаёт новую папку, удаление сохраняет копию. Импорт GitHub сохраняет снимок основной ветки; автоматического обновления расширения из GitHub нет.

Добавлены общие фильтры языка (английский, русский, тайский, китайский) и наличия перевода, поля публикации и редактирования. Старые записи без метаданных не считаются автоматически непереведёнными. Проверка установленных расширений доступна отдельным раскрываемым разделом той же вкладки.

Локально прошли 96 тестов Node.js и браузерные сценарии: 14 сочетаний темы/ширины главной, 35 экранов маскота в пяти темах и двух вариантах системной темы, вход удержанием заголовка, публикация ZIP/GitHub, совместная фильтрация и сохранение метаданных. Внешние ответы GitHub и публикация в каталоге в тестах заменены фикстурами. Снимки: `/tmp/tavernka-catalog-review/screens`. Android-сборка и выпуск проверяются после отправки ветки. Физический телефон в этих проверках не участвовал.
