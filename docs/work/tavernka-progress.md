# Тавернка: продолжение работы

Рабочая ветка: `tavernka-gpt`. Исходная версия: `b1f112058f0a4285044e0a464e2ccd112ab217f7`.
`main` не изменять. Публикация стабильного релиза и слияние не выполнялись.

Сверка с перепиской Claude: на начало работы main, tavernka-gpt и
claude/sillytavern-ai-assistant-lxb8ku совпадали. Описанные в скриншотах
новые изменения отсутствовали в исходных файлах GitHub.

## Выполнено

- Название Android-приложения и PWA: Тавернка. Существующий applicationId сохранён для совместимости обновлений и данных.
- Новые launcher-иконки для пяти плотностей Android, PWA-иконки и обложка README.
- Новый нейтральный маскот без книжки на груди в главном экране, веб-интерфейсе и виджете. Отдельные новые позы ещё не подключены: используется единый персонаж.
- Автоматический запуск перевода ответов отключён, включая сохранённую настройку и вызовы setAuto.
- Кнопка ручного перевода перенесена из дополнительного меню в панель сообщения; добавлена клавиатурная активация.
- Глоссарий заменяет термины за один проход, без каскадных замен; строки замены с `$` трактуются буквально.
- Перепроверка оформления и поведения: 82 теста Node и браузерные сценарии прошли. Подробности в [design-review.md](design-review.md). Проверка на физическом Android остаётся.

## Оставшиеся требования пользователя

- Глоссарий: предложения имён и терминов; отключение на время, для чата навсегда и для всех чатов. Проверить качество сохранения терминов после бесплатного перевода.
- Исправить проверку обновлений приложения и плагина, отображение результата с первого раза.
- Добавить чёрную, белую, коричневую темы, согласовать нативные и веб-цвета.
- Переписать гайд ПК → Android простыми пошаговыми инструкциями без снисходительных обещаний.
- Временно отключить оптимизацию/автопроверки чатов на сервере и показать понятное сообщение о приостановке.
- Убрать импорт по ссылке из интерфейса и связанных входов.
- Проверка установленных расширений: ограниченный статический анализ с честным описанием ограничений, без обещания антивирусной гарантии и без автоматической отправки кода модели.
- Исправить проверку подключения модели с главного экрана.
- Упростить навигацию и сворачивать второстепенные настройки; каталог в нижней панели, расширения в каталоге.
- Обновление страницы на вкладке сайтов.
- Проверить ресурсы WebView, восстановление после падения renderer и поведение на слабых устройствах.
- Уведомление об обновлении с раскрываемым списком изменений. Для доставки при закрытом приложении требуется определить механизм push; периодический опрос не обещать как мгновенную доставку.
- Проверить адаптивную иконку под масками Android, собрать APK, проверить пользовательские сценарии и сохранить следующие изменения отдельными коммитами.
