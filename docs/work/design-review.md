# Проверка изменений Тавернки

Проверены собственные изменения от `b1f1120` в ветке `tavernka-gpt`.
Направление оформления: [design-direction.md](design-direction.md), по unslop
Damir Sokolovsky / @heydamir (CC BY 4.0).

## Исправлено при проверке

- Экран знакомства: спокойный заголовок, конкретное описание, один маскот на первом шаге,
  текстовый счётчик шагов, равномерные отступы и читаемая вторичная типографика.
- Зоны нажатия в главном экране и знакомстве — минимум 48 CSS px; фокус клавиатуры,
  уменьшение анимации по системной настройке. Завершение знакомства сразу закрывает экран.
- Убран одинаковый машущий персонаж из мелких служебных блоков и сообщений об ошибках.
  Одобренный образ сохранён для знакомства и нейтральных пустых состояний.
- Подготовлен прозрачный foreground адаптивной Android-иконки. Видимая часть на xxxhdpi
  имеет радиус около 31.9 dp при безопасном радиусе 33 dp. Исходник:
  `docs/design/icon-foreground.png`, повторяемая подготовка: `bash scripts/build-icons.sh`.
- Новые изображения включены в офлайн-кэш PWA, изменена ревизия кэша.
- Кнопка перевода — настоящий HTML button с контурной SVG-иконкой. Она работает при
  клонировании шаблона сообщений, при показе старых и новых сообщений, с Enter и Space.
- Удалён неработающий переключатель автоперевода ответов из меню Android. Сохранённые
  настройки перевода ответов в расширении отключены. Отдельный существующий перевод
  собственных сообщений перед отправкой остаётся самостоятельной настройкой SillyTavern.
- Пустая правая часть глоссария сохраняет исходное написание и регистр имени.
  Проверены пересекающиеся имена, знаки пунктуации и буквальные строки с `$`.

## Выполненные проверки

- `npm test`: 82 теста успешно.
- `npm run test:browser`: Chromium, 320/390 px, светлая/тёмная темы, пять шагов знакомства,
  увеличенный шрифт, ошибка API, офлайн-кэш, ручной перевод, возврат оригинала,
  клавиатурное управление, отсутствие фоновых запросов перевода.
- `git diff --check`: без ошибок.
- Android APK успешно собран: [GitHub Actions #43601821640](https://github.com/yogurt5633-hub/st-app/actions/runs/43601821640), проверенный коммит `642dbfd110b50e69ad803980df20d1710391f699`. Стабильный релиз не опубликован.

Браузерные проверки используют реальные файлы приложения, имитацию Android bridge и
ответов SillyTavern API. Они не проверяют качество внешних переводчиков и не заменяют
проверку на физическом телефоне. Стабильный релиз и слияние в main не выполняются.

## Как повторить

Node.js 20.19+ (или 22/24), `npm ci`, `npm test`.
Для браузерной проверки: Chromium и `npm run test:browser`.
При другом пути Chromium задайте `CHROMIUM_PATH`; снимки по умолчанию попадают в
`/tmp/tavernka-review/screens`, путь можно изменить через `REVIEW_OUTPUT`.
Для подготовки размеров иконок нужен ImageMagick (`convert`).
