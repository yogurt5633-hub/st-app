# Windows и iPhone — первая версия 0.1.0

Разработка ведётся только в `tavernka-desktop-ios`. База — `1c86b6a` из `tavernka-gpt`. `main` и Android-ветка не изменяются. Linux исключён из текущего этапа по просьбе пользователя.

## Реализовано

- Windows: Electron-приложение с главной страницей и отдельными вкладками Таверны, Корректора и каталога. Страницы сервера не получают Node.js, preload или доступ к управлению компьютером; sandbox и contextIsolation включены.
- Выбор существующей установки SillyTavern; чтение порта из config.yaml; установка вложенных в приложение плагина и расширения через существующий установщик. Перед установкой сохраняются config.yaml, плагин и расширения в `.tavernka-backups/<timestamp>` внутри SillyTavern.
- Запуск через встроенный Node runtime Electron, без произвольных команд оболочки. Остановка только созданного приложением процесса; закрытие приложения также его останавливает.
- Подключение к уже работающему серверу по HTTP/HTTPS. Адрес сохраняется без логинов, паролей и параметров.
- iPhone/iPad: SwiftUI-приложение с WKWebView, сохранением адреса, четырьмя вкладками и общей постоянной WebKit-сессией. Обновление и возврат, сообщения об ошибках, HTTP Basic/Digest, стандартная проверка TLS, JavaScript-диалоги и скачивание с меню «Поделиться».
- iOS разрешает HTTP для локальной/частной сети (включая Tailscale), для публичных серверов требуется HTTPS. ATS-исключение относится к WebKit, поскольку пользователь задаёт произвольный локальный адрес. Перед публикацией его назначение нужно объяснить Apple.
- Отдельный workflow собирает установщик Windows и проверяет именно упакованное приложение на тестовом сервере. На macOS собирает iOS-приложение и выполняет XCTest в симуляторе. Никаких стабильных релизов и автообновлений workflow не публикует.

## Запуск разработчиком

Windows:

```powershell
npm ci --prefix desktop
npm start --prefix desktop
npm run dist:win --prefix desktop
```

Нужна уже установленная и хотя бы один раз запущенная SillyTavern с зависимостями. Путь `dataRoot`, отличный от стандартного `data`, пока не поддерживается автоматическим установщиком. Выбранный сервер с нестандартной конфигурацией можно запускать отдельно и подключаться по адресу.

macOS с Xcode и XcodeGen:

```sh
xcodegen generate --spec ios/project.yml
open ios/Tavernka.xcodeproj
```

Выберите схему Tavernka и симулятор iPhone. Для телефона выберите свою Apple Development Team и доступный bundle identifier. Проект и схема воспроизводимо создаются из `project.yml`.

## Пока не реализовано / не проверено

- Автоматическое скачивание и первичная установка SillyTavern и её зависимостей на чистую Windows. Первая версия использует установленную Таверну.
- Подпись Windows сертификатом издателя, автообновления, трей, настройка доступа с телефона одной кнопкой.
- TestFlight/App Store: нужны Apple Developer, подпись и настройка распространения. ZIP для симулятора не устанавливается на физический iPhone.
- Автономный запуск SillyTavern внутри iPhone. Приложение является клиентом сервера.
- Проверки с реальными чатами, провайдерами, устройствами, клавиатурой iPhone и работа при уходе в фон. Тестовый сервер в CI не заменяет этот этап.
- Паритет Android-функций (уведомления, фоновые задачи, share-to-app и управление Termux) не заявляется.
- Настройка внешней сети остаётся ручной: нельзя выключать защиту SillyTavern ради удобства. Локальный запуск сохраняет его текущие сетевые настройки.

Архитектура сверена с официальными рекомендациями [Electron Security](https://www.electronjs.org/docs/latest/tutorial/security), [WKWebsiteDataStore](https://developer.apple.com/documentation/webkit/wkwebsitedatastore) и [ATS Web Content](https://developer.apple.com/documentation/BundleResources/Information-Property-List/NSAppTransportSecurity/NSAllowsArbitraryLoadsInWebContent).

## Установка первой Windows-версии

1. Запустите `Tavernka-0.1.0-Windows-x64-Setup.exe`. Сборка тестовая, сертификата подписи издателя пока нет.
2. Выберите папку уже установленной и хотя бы раз запущенной SillyTavern. Остановите её, если она открыта отдельно.
3. Нажмите «Установить Корректор», затем «Запустить» и откройте вкладку «Таверна».

Можно также просто указать адрес уже работающего сервера. Удалённую Таверну приложение не запускает.

На момент завершения работы `main` и `tavernka-gpt` были обновлены другой работой до `1f75b070`. Эта разработка их не меняла и не объединяла: её база остаётся `1c86b6a`, все новые коммиты находятся только в `tavernka-desktop-ios`.
