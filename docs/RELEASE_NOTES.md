Управление запущенной таверной без лагов, конвертация для SillyTavern, живой каталог и окно «Что нового».

- Во вкладке «Настройки → Таверна» появились разделы «Пресеты», «Лорбук», «Карточки», «Расширения», «Регексы» и «Антивирус» — выбирайте пресеты, настраивайте промпты, включайте глобальные лорбуки и расширения, редактируйте карточки и правила Regex прямо из Тавернки без открытия тяжёлых меню самой SillyTavern.
- Проверка установленных расширений перенесена из каталога во вкладку «Таверна → Антивирус».
- В «Настройки → Ещё» добавлена «Конвертация для SillyTavern»: превращает JSON-карточки в готовые PNG-карточки SillyTavern (V2 + V3), извлекает вшитые лорбуки и регексы, упаковывает расширения в ZIP и сразу устанавливает в таверну или скачивает файл.
- При появлении новинок в каталоге на кнопке «Каталог» в нижней панели в реальном времени загорается метка с количеством новых записей.
- Вместо сворачивающегося блока в разделе обновлений теперь после обновления приложения поверх экрана открывается окно «Что нового в Тавернке».
- В «Оптимизацию» перенесены «Здоровье карточек», «История» и «Скрытые замечания», а из «Ещё» убрана дублирующая кнопка «Каталог».
- В «Настройках» разделы «Подключение» и «Модели» теперь всегда открыты, а «Какая модель для какой задачи» и «Уведомления» убраны.
- В «Расходах» и «Настройках» добавлены кнопки «Сбросить статистику» и «Откат до заводских настроек».
- Устранены подвисания при переключении вкладок.

Установите korrektor.apk поверх прежней версии, затем обновите плагин до 0.4.30 в «Главная → Обновления» (или перезапустите таверну из приложения).
