# Гайд: SillyTavern и Корректор с нуля

Пошагово, без знания программирования. Выберите свой путь:

- [Только телефон (Android)](#1-телефон-android): таверна живёт в телефоне, приложение «Корректор» запускает её одной кнопкой.
- [Только компьютер](#2-компьютер-windows-macos-linux): таверна на ПК, Корректор открывается в браузере.
- [Телефон и компьютер вместе](#3-связать-телефон-и-компьютер): открыть таверну с ПК на телефоне и держать чаты одинаковыми на обоих.

Если что-то не получилось — загляните в [частые ошибки](#5-частые-ошибки). Там собрано всё, что уже присылали пользователи.

---

## 1. Телефон (Android)

### 1.1. Поставьте Termux

Termux — это «компьютер внутри телефона», в нём работает таверна.

1. Скачайте Termux **из F-Droid** (<https://f-droid.org/packages/com.termux/>) или **с GitHub** (<https://github.com/termux/termux-app/releases>, файл `termux-app_..._universal.apk`).
   Termux из Google Play устарел и не работает с приложением.
2. Установите и откройте его один раз. Дождитесь, пока он закончит первую настройку и покажет строку с `$`.
3. Чтобы Android не выключал таверну в фоне: Настройки телефона → Приложения → Termux → Батарея → **«Без ограничений»** (на Xiaomi ещё «Автозапуск»: включить).

### 1.2. Поставьте приложение «Корректор»

1. Скачайте `korrektor.apk` со страницы последнего выпуска: <https://github.com/yogurt5633-hub/st-app/releases/latest>.
2. Установите его. Android спросит, можно ли браузеру устанавливать приложения: разрешите.
3. Откройте «Корректор». Покажется знакомство, потом вкладка «Главная» с шагами первой настройки.

### 1.3. Первая настройка (один раз)

На «Главной» по порядку:

1. **«Разрешить»** — разрешение «Выполнять команды в среде Termux».
   Если окно не появилось: Настройки телефона → Приложения → Корректор → Разрешения → Дополнительные разрешения → «Выполнять команды в среде Termux».
2. **Команда для Termux.** Нажмите «Скопировать», откройте Termux, вставьте (долгое нажатие → Paste) и нажмите Enter:

   ```bash
   mkdir -p ~/.termux && echo 'allow-external-apps = true' >> ~/.termux/termux.properties && termux-reload-settings
   ```

   Вернитесь в приложение и нажмите **«Проверить»**: шаг отметится как выполненный.
3. **SillyTavern.**
   - Таверны ещё нет → **«Установить SillyTavern»**. Откроется Termux, там видно, как идёт установка. Это 5–15 минут, телефон лучше держать на зарядке и в Wi‑Fi. Корректор поставится вместе с таверной.
   - Таверна уже есть → ничего ставить не нужно, приложение найдёт её само. Если вы запускаете её своей командой (например `st`), впишите эту команду в поле **«Команда запуска в Termux»**.
4. Нажмите **«Запустить»**. Первый запуск долгий (несколько минут): ставятся зависимости. Последнюю строку вывода видно прямо на «Главной». Следующие запуски — быстрее.

Когда таверна запустится, приложение само откроет вкладку «Таверна».

### 1.4. Подключите модель (ключ API)

1. Вкладка **«Сайты»** → выберите провайдера (OpenRouter, Элизиум, DDTokens или свой). Войдите, пополните баланс, создайте ключ и скопируйте его.
   Вход через Google внутри приложений не работает: нажмите «В браузере».
2. Вкладка **«Таверна»** → значок вилки (API Connections) вверху.
3. API: **Chat Completion**. Источник (Chat Completion Source): ваш провайдер. Для Элизиума, DDTokens и других «прокси» выберите **Custom (OpenAI-compatible)** и впишите их адрес из инструкции провайдера.
4. Вставьте ключ, нажмите **Connect**, выберите модель.

Ключ хранится только в таверне, Корректор его не читает и никуда не отправляет. Проверить ключ: вкладка «Корректор» → «Ещё» → «Подключение к модели».

### 1.5. Что дальше

- Над таверной есть строка быстрых кнопок: обновить страницу, **«Перевод»**, фоны, аватар, модель и пресет.
- Вкладка «Корректор» показывает замечания по чатам и инструменты: расходы, сжатие чата, резервную копию, импорт карточек. Замечания не нужны — «Выключить замечания» вверху ленты, справа: Корректор перестанет проверять и присылать находки, остальное (перевод, каталог, копии) работает. Включить — там же или в «Настройках».
- Обновления приложения и Корректора приходят сами: сверху появляется плашка «Обновить».

## 2. Компьютер (Windows, macOS, Linux)

### 2.1. Что нужно поставить один раз

1. **Node.js** — версия LTS с <https://nodejs.org>. Установка с галочками по умолчанию.
2. **Git** — <https://git-scm.com/downloads>. Тоже всё по умолчанию.

Проверка: откройте «Командную строку» (Win+R → `cmd` → Enter) и выполните `node -v` и `git --version`. Обе команды должны показать версию.

### 2.2. SillyTavern

Если таверна уже стоит — переходите к 2.3.

1. Выберите простую папку **не в OneDrive, не в «Документах» и не в Program Files**, например `C:\AI` или `D:\AI`. В этих особых папках Windows часто запрещает запись, и установка ломается.
2. В командной строке:

   ```bat
   cd /d D:\AI
   git clone https://github.com/SillyTavern/SillyTavern -b release
   ```

3. Откройте папку `D:\AI\SillyTavern` и запустите **`Start.bat`**. Первый раз он ставит зависимости (пару минут), потом сам откроет браузер на <http://127.0.0.1:8000>.
4. Чёрное окно с консолью — это и есть таверна. Пока оно открыто, таверна работает. Закрыли окно — таверна выключилась.

macOS и Linux: то же самое в Терминале, только запуск — `./start.sh`.

### 2.3. Корректор

1. **Закройте таверну** (окно консоли), иначе Windows может не дать заменить файлы.
2. В командной строке:

   ```bat
   cd /d D:\AI
   git clone https://github.com/yogurt5633-hub/st-app korrektor
   node korrektor\scripts\install.mjs "D:\AI\SillyTavern"
   ```

   Путь в кавычках — папка, где лежит `Start.bat` таверны.
   Нет Git? На странице <https://github.com/yogurt5633-hub/st-app> нажмите Code → Download ZIP, распакуйте и выполните ту же команду `node ...\scripts\install.mjs "путь к SillyTavern"` из распакованной папки.
3. Установщик напишет «Готово». Запустите `Start.bat` снова.
4. Корректор открывается в браузере: <http://127.0.0.1:8000/api/plugins/korrektor/app/>. В самой таверне в меню волшебной палочки появятся «Фоны», «Аватар персонажа» и «Перевести чат».

**Обновить Корректор на ПК:**

```bat
cd /d D:\AI\korrektor
git pull
node scripts\install.mjs "D:\AI\SillyTavern"
```

## 3. Связать телефон и компьютер

Можно два варианта, они друг другу не мешают:

- **Открыть таверну с ПК на телефоне.** Ролите на телефоне, а работает компьютер. Термукс для этого не нужен.
- **Синхронизация.** Таверна стоит и там, и там, а чаты, карточки и лорбуки одинаковые на обоих.

### 3.1. Подготовьте таверну на ПК (один раз)

1. Узнайте адрес компьютера в сети: в командной строке `ipconfig` → строка **IPv4-адрес** у вашего Wi‑Fi или Ethernet, например `192.168.1.23`.
   macOS: Системные настройки → Сеть. Linux: `ip a`.
2. Закройте таверну и откройте в Блокноте файл `config.yaml` в папке SillyTavern. Поменяйте:

   ```yaml
   listen: true
   whitelistMode: true
   whitelist:
     - ::1
     - 127.0.0.1
     - 192.168.1.0/24
   ```

   Последняя строка пускает все устройства вашей домашней сети. Если ваш адрес `192.168.0.15`, пишите `192.168.0.0/24`: первые три числа как у компьютера, в конце `0/24`.

   Для Tailscale добавьте ещё строку `- 100.64.0.0/10`.

   **Другой вариант** — вход по паролю вместо списка адресов:

   ```yaml
   listen: true
   whitelistMode: false
   basicAuthMode: true
   basicAuthUser:
     username: "придумайте-логин"
     password: "придумайте-пароль"
   ```

   Никогда не ставьте `whitelistMode: false` без `basicAuthMode: true`, иначе таверну и ваши ключи увидит любой, кто достучится до компьютера.
3. Запустите `Start.bat`. Windows спросит про доступ к сети для Node.js: отметьте **«Частные сети»** и нажмите «Разрешить».
   Если не спросил, а телефон не подключается: Параметры → Сеть и Интернет → ваш Wi‑Fi → Тип профиля сети → **«Частная»**.
4. Проверка: на телефоне в Chrome откройте `http://192.168.1.23:8000` (ваш адрес). Должна открыться таверна.

### 3.2. Открыть таверну с ПК в приложении

1. «Главная» → раздел **«Таверна на ПК»** → «Адрес таверны на компьютере»: `http://192.168.1.23:8000`.
2. Нажмите **«Открыть таверну с ПК»**. Сверху появится переключатель «Телефон / ПК».
3. Если на ПК включён пароль, приложение спросит логин и пароль один раз.

Запускают и обновляют таверну на ПК на самом компьютере: кнопки «Запустить» и «Обновить» в приложении управляют только таверной в телефоне.

**Вне дома** (мобильный интернет): поставьте **Tailscale** (<https://tailscale.com>) на компьютер и на телефон, войдите в один аккаунт. У компьютера появится адрес вида `100.101.102.103`: его и впишите вместо `192.168.…`. Не открывайте таверну в интернет напрямую (проброс портов на роутере) без пароля.

### 3.3. Синхронизация чатов

Нужно, чтобы Корректор стоял в обеих тавернах (телефон — шаг 1, ПК — шаг 2.3) и таверна на ПК была видна с телефона (шаг 3.1).

1. На телефоне: вкладка «Корректор» → «Ещё» → **«Связь с ПК»**.
2. «Адрес другой таверны» — тот же `http://192.168.1.23:8000`. Логин и пароль — если включали.
3. **«Проверить связь»**, потом **«Синхронизировать сейчас»**.
4. Можно включить «Буду синхронизировать сам каждые 15 минут».

Что переносится: чаты, групповые чаты, карточки, лорбуки, пресеты, фоны, аватарки персон и галереи персонажей. Что **не** переносится: настройки таверны и ключи API — у каждой таверны свои. Ничего не удаляется: заменённые файлы сначала уходят в резервные копии. Если один чат меняли на обоих устройствах между синхронизациями, новая версия остаётся, а вторая появляется рядом отдельным чатом «… копия с телефона» или «… копия с ПК».

## 4. Перевод чата

- **Новые ответы:** строка над таверной → «Перевод» → «Переводить новые ответы», выберите язык. Модель по-прежнему видит оригинал, перевод только показывается. Когда ответ дописан, перевод появляется в нём по частям: готовый кусок сразу встаёт на место своего абзаца, остальное пока на английском, сбоку тонкая полоска — «переводится». Выключается в окне перевода: «Показывать перевод по частям».
- **Старые сообщения:** «Перевод» → **«Старые сообщения»** (или в самой таверне: волшебная палочка → «Перевести чат»). Выберите последние 20, 50 или весь чат и чем переводить:
  - «Бесплатно» — Google, если не отвечает, то Bing и Яндекс;
  - «Модель Корректора» — дешёвая модель из настроек Корректора. Лучше держит ролевой стиль и разметку, тратит немного денег.

  Сообщения переводятся по одному. Если какое-то не получилось, остальные всё равно переведутся, а кнопка «Повторить пропущенные» доделает остаток. «Стоп» останавливает перевод, «Показать оригинал» убирает перевод. Переводы, у которых пропал конец, «Перевести» делает заново сам.
- **Одно сообщение:** меню сообщения (⋯) → кнопка с языком. Непереведённое переводится сразу, у переведённого можно выбрать «Перевести заново» или «Показать оригинал». Это кнопка Корректора, она стоит на месте кнопки перевода таверны.
- **Свой ключ для перевода:** «Перевод» → «Модель Корректора» → «Свой ключ для перевода…» (или Корректор → Настройки → «Свой ключ для перевода»). Выберите сервис (OpenRouter, OpenAI, Claude, Gemini, DeepSeek, Mistral или свой адрес), вставьте ключ, укажите модель и нажмите «Проверить и сохранить»: Корректор попросит модель перевести одну строку и покажет, работает ли ключ. Перевод тогда не тратит ключ таверны. Ключ хранится только в этой таверне, не попадает в резервные копии и синхронизацию и обратно не показывается.
- **Журнал перевода:** «Перевод» → «Журнал». Там видно, что и чем переводилось, сколько заняло, где ответ оборвался и что Корректор сделал. «Проверить переводы чата» находит обрезанные переводы. «Копировать» — чтобы прислать журнал, если что-то не так.

Встроенный перевод таверны («Translate whole chat») обрывается на первой ошибке с сообщением «Failed to translate chat». Используйте «Старые сообщения» из Корректора.

## 5. Частые ошибки

| Что видно | Что делать |
|---|---|
| `EIO`, `EPERM` или `Access is denied` при `install.mjs` на Windows | Закройте таверну и окна Проводника в её папке и повторите. Если папка в OneDrive или «Документах», перенесите SillyTavern в `D:\AI` или подобную. Ещё помогает: Безопасность Windows → Защита от вирусов → Управление защитой от программ-шантажистов → «Контролируемый доступ к папкам» — выключить или разрешить `node.exe`. Установщик версии 0.4.3 и новее сам повторяет запись и подсказывает это же. |
| `node` не является внутренней или внешней командой | Не установлен Node.js или командная строка была открыта до установки. Поставьте Node.js LTS и откройте новую командную строку. |
| Не нашёл SillyTavern | Укажите путь в кавычках к папке, где лежат `server.js` и `Start.bat`: `node scripts\install.mjs "D:\AI\SillyTavern"`. |
| Корректора нет в таверне после установки | В консоли таверны при запуске должна быть строка `[korrektor] … готов`. Нет её — проверьте, что в `config.yaml` стоит `enableServerPlugins: true`, и перезапустите таверну. |
| Таверна запускается, только когда открываю Termux; в Termux много вкладок | Так было в приложении 1.0.24 и раньше: оно запускало таверну в новой вкладке Termux, а Termux начинает её выполнять, только когда его открывают. Обновите приложение. Старые вкладки закройте: уведомление Termux → «Exit», потом «Запустить» в приложении. Теперь таверна работает в фоне Termux, без вкладок. |
| «Termux пока не выполнил команду» | Android придержал Termux в фоне. Откройте Termux на пару секунд и вернитесь. Чтобы не повторялось: батарея для Termux — «Без ограничений» (шаг 1.1). |
| «Termux не ответил» | Выполните в Termux команду из шага 1.3, полностью закройте Termux (уведомление → Exit) и откройте снова, потом «Проверить». Termux должен быть из F-Droid или GitHub. |
| Таверна грузится 5–10 минут | Так бывает только в первый раз и после обновления таверны: ставятся зависимости. Держите телефон на зарядке и в Wi‑Fi, не сворачивайте Termux в первые минуты. Дальше запуск быстрый. |
| Таверна перезагружается, когда возвращаюсь в приложение | Обновите приложение до 1.0.34 или новее: «Главная» → «Чтобы таверна не перезагружалась» → включите «Держать таверну открытой» и нажмите «Разрешить работу в фоне». Если перезагрузка всё же случится, откроется тот же чат, на том же месте, с недописанным сообщением. |
| Таверна сама выключается в фоне | Батарея для Termux: «Без ограничений» (шаг 1.1). На Xiaomi, Huawei, Samsung ещё уберите Termux из «Спящих приложений» и разрешите автозапуск. |
| «Команда запуска закончилась, а SillyTavern так и не запустился» | В поле «Команда запуска» не та команда. Оставьте поле пустым — приложение найдёт таверну само — или впишите `cd ~/SillyTavern && ./start.sh`. |
| Обновление Корректора «не применяется» | В версии 0.4.3 это исправлено. Нажмите «Обновить» и дождитесь перезапуска таверны. Если GitHub недоступен, в журнале будет «Не удалось скачать обновление»: проверьте интернет или включите VPN и повторите. |
| Телефон не видит таверну на ПК | Проверьте по шагам 3.1: `listen: true`, адрес сети в `whitelist`, тип сети «Частная», брандмауэр разрешил Node.js, телефон в той же Wi‑Fi (не в гостевой). Адрес — `http://`, не `https://`, и с `:8000` в конце. |
| `Forbidden` или «IP not whitelisted» при открытии с телефона | Адрес телефона не попал в `whitelist`. Добавьте `192.168.X.0/24` вашей сети (шаг 3.1) и перезапустите таверну. |
| Перевод наполовину: часть ответа осталась на английском | В Корректоре 0.4.5 и новее длинные ответы переводятся небольшими кусками, и кусок, вернувшийся на английском, переводится заново. Включите «Перевод» → «Переводить новые ответы» (переводит Корректор, а не встроенный перевод таверны). Если всё равно бывает — выберите другой переводчик или «Модель Корректора». |
| Перевод обрывается: переведено только начало | В Корректоре 0.4.20 и новее перевод, который вышел заметно короче оригинала (модель упёрлась в лимит длины или переводчик потерял конец), переводится заново по частям. Старые обрезанные переводы: «Перевод» → «Перевести» — они переведутся заново; или кнопка с языком в меню сообщения → «Перевести заново». Если повторяется — «Перевод» → «Журнал» → «Копировать» и пришлите текст. |
