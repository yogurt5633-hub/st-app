# Тавернка — подключение с компьютера к Android

Тавернка открывает SillyTavern на телефоне. SillyTavern может работать на компьютере или в Termux на самом телефоне. Ниже сначала описан вариант с компьютером.

Эта инструкция относится к тестовой ветке `tavernka-gpt`. Сборки этой ветки находятся в артефактах GitHub Actions. Страница стабильных релизов содержит прежнюю версию приложения.

## 1. Проверьте SillyTavern на компьютере

1. Откройте папку SillyTavern. На Windows в ней находится `Start.bat`.
2. Дважды нажмите `Start.bat`. На macOS и Linux откройте терминал в этой папке и выполните `./start.sh`.
3. Подождите, пока откроется страница SillyTavern. Обычно её адрес `http://127.0.0.1:8000`.
4. Откройте любой чат и убедитесь, что страница работает.
5. Оставьте окно запуска открытым. Оно поддерживает работу сервера. Компьютер должен оставаться включённым.

Если SillyTavern ещё не установлен, воспользуйтесь официальной инструкцией для своей системы. [Установка SillyTavern](https://docs.sillytavern.app/installation/)

## 2. Установите плагин из тестовой ветки

Плагин добавляет перевод, каталог, резервные копии и связь с приложением. Для команд ниже нужны Git и Node.js, которые используются при установке SillyTavern.

1. Остановите SillyTavern, закрыв окно запуска.
2. На Windows откройте папку, рядом с которой лежит SillyTavern. В адресной строке Проводника напишите `cmd` и нажмите Enter. Откроется командная строка в этой папке.
3. Выполните команду и дождитесь появления строки ввода.

```bat
git clone --branch tavernka-gpt https://github.com/yogurt5633-hub/st-app tavernka
```

4. Установите плагин. В кавычках укажите свою папку SillyTavern. Ниже дан пример пути.

```bat
node tavernka\scripts\install.mjs "D:\AI\SillyTavern"
```

Для macOS и Linux команда имеет такой вид.

```sh
node tavernka/scripts/install.mjs "$HOME/SillyTavern"
```

5. Дождитесь сообщения об окончании установки. Снова запустите SillyTavern.
6. На компьютере откройте `http://127.0.0.1:8000/api/plugins/korrektor/app/`. Должна появиться страница Тавернки. Если вы поменяли порт SillyTavern, подставьте свой порт.

Если установщик сообщил об ошибке, сохраните её текст. Проверьте путь к папке и закройте приложения, которые могут держать её файлы открытыми.

## 3. Разрешите подключение телефона

Компьютер и телефон подключите к одной домашней сети Wi-Fi. Компьютер также может быть подключён к этому роутеру кабелем.

1. На Windows нажмите Win+R, введите `cmd`, нажмите Enter.
2. Введите `ipconfig` и нажмите Enter.
3. Найдите IPv4-адрес активного Wi-Fi или Ethernet. Запишите его. Например, `192.168.1.23`.
4. На телефоне откройте настройки текущей сети Wi-Fi и найдите IP-адрес телефона. Например, `192.168.1.45`.
5. Остановите SillyTavern. В его папке откройте файл `config.yaml` текстовым редактором.
6. Найдите существующие параметры `listen`, `whitelistMode` и список `whitelist`. Установите `listen: true`, оставьте `whitelistMode: true` и добавьте в список точный IP-адрес телефона. Отступы перед строками списка сохраняйте.

```yaml
listen: true
whitelistMode: true
whitelist:
  - ::1
  - 127.0.0.1
  - 192.168.1.45
```

7. Сохраните файл и снова запустите SillyTavern.
8. Если Windows спросит о доступе Node.js к сети, разрешите его для своей частной сети.
9. На телефоне откройте браузер. В адресную строку введите адрес компьютера с портом, например `http://192.168.1.23:8000`.
10. Убедитесь, что появилась SillyTavern. Теперь можно подключать приложение.

В примере `.23` — компьютер, `.45` — телефон. Используйте адреса своих устройств. После изменения адреса телефона обновите список доступа. Подробнее параметры описаны в официальной документации. [Удалённые подключения](https://docs.sillytavern.app/usage/remoteconnections/)

## 4. Откройте эту таверну в приложении

1. Установите тестовый `korrektor.apk`, собранный из `tavernka-gpt`.
2. Откройте Тавернку. Пройдите знакомство или нажмите «Пропустить».
3. На «Главной» раскройте «Подключение и запуск».
4. В разделе «Таверна на ПК» вставьте адрес, который уже открылся в браузере телефона. Например, `http://192.168.1.23:8000`.
5. Нажмите «Открыть таверну с ПК».
6. Если сервер запросит логин и пароль, введите данные своего сервера.
7. Откройте вкладку «Таверна» и выберите чат.

Компьютер выполняет работу сервера. Для этого режима Termux на телефоне не требуется. Запуск и обновление SillyTavern на компьютере выполняются на компьютере.

## 5. Подключите модель

1. В SillyTavern откройте «API Connections» значком подключения.
2. Выберите тип подключения и провайдера по инструкции своего сервиса.
3. Вставьте ключ API и адрес сервиса, если он нужен. Нажмите Connect и выберите модель.
4. Отправьте короткое сообщение в чат, чтобы проверить получение ответа.
5. На главной Тавернки нажмите «Подключение к модели», затем «Проверить». Если провайдер требует пробного запроса, доступна отдельная кнопка. Такой запрос расходует токены.

Тавернка использует подключение, сохранённое в SillyTavern. Баланс и доступность конкретной модели проверяются у провайдера.

## 6. Перевод и глоссарий

### Одно сообщение

Нажмите кнопку перевода прямо в панели сообщения. После перевода повторное нажатие открывает действия, включая «Показать оригинал». Автоматический перевод новых ответов отключён.

### Несколько сообщений

Нажмите «Перевод» над таверной. Выберите язык, диапазон сообщений и переводчик, затем запустите перевод. «Стоп» останавливает текущую задачу.

### Словарь имён

1. В переводе откройте «Указания и глоссарий».
2. Запишите по одной паре на строку.

```text
Hunter Association = Ассоциация охотников
Ihan = Ихан
Gate = Врата
```

3. Пустая правая часть сохраняет исходное написание. Например, `Ihan =`.
4. Нажмите «Сохранить». Новые правила применятся при следующем переводе. Для уже переведённого сообщения выберите перевод заново.
5. В разделе автодетекта появляются предложения повторяющихся имён из текущего чата. Нажмите подходящее имя, укажите перевод и сохраните.
6. Автодетект можно поставить на час, выключить для текущего чата или для всех чатов. Эти переключатели сохраняются на текущем устройстве.

Бесплатный перевод защищает термины от изменения. Если переводчик потеряет защитный маркер, появится ошибка. Модель получает термины и указания в своём запросе, качество её ответа зависит от выбранной модели.

## 7. Где находятся инструменты

- «Главная» содержит запуск, сворачиваемые настройки, оформление и обновления.
- «Таверна» открывает SillyTavern.
- «Каталог» содержит материалы для историй и вкладку установленных расширений.
- «Сайты» открывает сайты провайдеров. Кнопка «Обновить» перезагружает текущую страницу.
- В веб-интерфейсе через «Ещё» доступны расходы, резервные копии, история и связь с ПК.

Оптимизация и автоматические проверки чатов временно приостановлены из-за нестабильной работы и расхода токенов. Импорт по ссылке временно отключён. Локальная проверка расширений показывает подозрительные конструкции и места для просмотра кода. Отсутствие находок не гарантирует безопасность расширения.

## 8. Если SillyTavern работает на телефоне

1. Установите Termux из F-Droid или официальных выпусков GitHub. Откройте его и дождитесь строки ввода. [Termux](https://github.com/termux/termux-app)
2. В Тавернке раскройте «Подключение и запуск». Разрешите выполнение команд в Termux.
3. Скопируйте команду, которую показывает приложение, вставьте её в Termux долгим нажатием и нажмите Enter.
4. Вернитесь в Тавернку и нажмите «Проверить».
5. Если SillyTavern ещё нет, нажмите «Установить SillyTavern» и дождитесь окончания установки в Termux.
6. Если вы уже используете свою команду запуска, впишите её в соответствующее поле.
7. Нажмите «Запустить», затем откройте «Таверна».

Если Android останавливает сервер в фоне, раскройте «Работа в фоне». Там находятся настройки батареи и удержания приложения.

## 9. Обновления и частые ошибки

**Проверить обновления.** На главной раскройте «Обновления» и нажмите «Проверить». Рядом с приложением и плагином появятся версии либо причина ошибки. Обновление APK и обновление плагина выполняются отдельно.

**Обновить тестовый плагин на ПК.** Остановите SillyTavern, откройте терминал в папке `tavernka` и выполните следующие команды. Затем снова запустите SillyTavern.

```sh
git pull --ff-only origin tavernka-gpt
node scripts/install.mjs "ПУТЬ-К-SillyTavern"
```

**Телефон не открывает страницу.** Сначала проверьте её в браузере телефона. Убедитесь, что сервер запущен, оба устройства в одной сети, IP-адреса записаны верно и IP телефона есть в списке доступа.

**403 или Access denied.** Сверьте адрес телефона со списком `whitelist`. После изменения `config.yaml` перезапустите сервер.

**Плагин не найден.** Проверьте страницу `/api/plugins/korrektor/app/` на компьютере. Повторите установку плагина в ту папку SillyTavern, из которой действительно запускается сервер.

**Переводчик сообщил об ошибке.** Проверьте доступность выбранного сервиса. Для модели проверьте ключ, баланс и название модели. Сохраните сообщение об ошибке из журнала перевода.

**Приложение закрывается.** Запишите модель телефона, версию Android и Android System WebView, а также действие перед закрытием. В «Помощи» доступен отчёт о проблеме.

Проверка обновлений пока использует периодические запросы. Доставка push-уведомлений всем устройствам сразу после публикации ещё требует отдельного сервиса.
