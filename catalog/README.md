# Каталог Корректора

Список, который приложение показывает в разделе «Каталог». Он загружается прямо из этого файла на GitHub, поэтому новые записи появляются у всех без обновления приложения.

Добавлять можно только то, что автор разрешил распространять. В записи всегда указывается автор.

## Как добавлять (для автора каталога)

Проще всего — из приложения: «Корректор» → «Ещё» → «Каталог», долгое нажатие на заголовок «Каталог».

1. Один раз вставьте токен GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access: только этот репозиторий. Permissions → Contents: Read and write.
2. Выберите тип, файл из своей таверны или с телефона, впишите название, автора, описание и теги, отметьте «Автор разрешил распространять» и нажмите «Опубликовать».

Корректор кладёт файл в `catalog/files/<тип>s/` и дописывает запись наверх `catalog.json`. У всех она появится через несколько минут, без обновления приложения. Из пресетов перед публикацией убираются пароли, адреса прокси и всё похожее на ключи. Там же можно убрать запись и указать ссылку, куда пользователи присылают свои файлы (кнопка «Предложить своё»). Она хранится в поле `submit` этого файла.

Токен хранится только в таверне автора (`korrektor/catalog-admin.json`): в резервные копии и синхронизацию он не попадает.

Можно и руками: загрузить файл в `catalog/files/` и дописать запись в `catalog.json` по формату ниже.

## Формат записи

```json
{
    "id": "uniq-id",
    "type": "lorebook",
    "name": "Название",
    "author": "Автор",
    "description": "Пара предложений: что это и для чего",
    "tags": ["фэнтези"],
    "url": "https://прямая-ссылка-на-файл.json",
    "page": "https://страница-автора"
}
```

- `type`: `lorebook` (JSON лорбука SillyTavern), `preset` (JSON пресета Chat Completion) или `card` (PNG карточки персонажа).
- `url`: прямая ссылка на сам файл, только `https://`. Ссылка на страницу со скачиванием не подойдёт.
- `page`: необязательно, страница автора или обсуждения.
- `added`: необязательно, дата добавления `ГГГГ-ММ-ДД`.

Поле `submit` в корне файла — ссылка, куда присылать предложения (например `https://t.me/ник`).

При установке файл скачивается в SillyTavern под своим названием. Уже существующие файлы не перезаписываются: новый получит имя с номером.
