# Каталог Корректора

Список, который приложение показывает в разделе «Каталог». Он загружается прямо из этого файла на GitHub, поэтому новые записи появляются у всех без обновления приложения.

Добавлять можно только то, что автор разрешил распространять. В записи всегда указывается автор.

## Как добавлять (для автора каталога)

Проще всего — из приложения: откройте «Каталог» в нижней панели и удерживайте заголовок «Каталог» сверху.

1. Один раз вставьте токен GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access: только этот репозиторий. Permissions → Contents: Read and write.
2. Выберите тип и источник. Пресет, лорбук и карточку можно взять из своей таверны или с телефона. Для расширения доступны ZIP с телефона и ссылка на публичный репозиторий GitHub.
3. Впишите название, автора, описание и теги. Укажите язык и наличие перевода: по ним пользователи фильтруют все типы материалов. Отметьте «Автор разрешил распространять» и нажмите «Опубликовать».

Корректор кладёт файл в `catalog/files/<тип>s/` и дописывает запись наверх `catalog.json`. У всех она появится через несколько минут, без обновления приложения. Из пресетов перед публикацией убираются пароли, адреса прокси и всё похожее на ключи. Там же можно убрать запись и указать ссылку, куда пользователи присылают свои файлы (кнопка «Предложить своё»). Она хранится в поле `submit` этого файла.

Токен хранится только в таверне автора (`korrektor/catalog-admin.json`): в резервные копии и синхронизацию он не попадает.

Можно и руками: загрузить файл в `catalog/files/` и дописать запись в `catalog.json` по формату ниже.

## Расширения

Выберите «Расширение» в админке. ZIP должен содержать `manifest.json` и указанные в нём файлы JavaScript или CSS — в корне архива либо в одной общей папке. Максимум: 20 МБ архива, 10 МБ на файл, 40 МБ после распаковки и 2000 файлов и папок. Символические ссылки, выход за папку расширения и шифрованные архивы не поддерживаются.

Для GitHub укажите `https://github.com/автор/репозиторий` и нажмите «Загрузить с GitHub». В каталог попадёт проверенный ZIP текущей основной ветки. Это снимок версии: последующие изменения исходного репозитория не заменяют опубликованный файл автоматически. Скачивание и проверка не публикуют запись; после заполнения формы нажмите «Опубликовать».

При установке расширение получает отдельную папку в пользовательском каталоге расширений SillyTavern. После установки или удаления обновите страницу таверны. При удалении копия сохраняется в `korrektor/backups/catalog/`. Проверка структуры архива не определяет безопасность JavaScript: устанавливайте расширения от авторов, которым доверяете. Проверка уже установленных расширений остаётся во вкладке «Расширения», в сворачиваемом разделе.

## Формат записи

```json
{
    "id": "uniq-id",
    "type": "lorebook",
    "name": "Название",
    "author": "Автор",
    "description": "Пара предложений: что это и для чего",
    "tags": ["фэнтези"],
    "url": "https://прямая-ссылка-на-файл.json",
    "page": "https://страница-автора",
    "language": "ru",
    "translated": true
}
```

- `type`: `lorebook` (JSON лорбука SillyTavern), `preset` (JSON пресета Chat Completion), `card` (PNG карточки персонажа) или `extension` (ZIP расширения).
- `url`: прямая ссылка на сам файл, только `https://`. Ссылка на страницу со скачиванием не подойдёт.
- `page`: необязательно, страница автора или обсуждения.
- `added`: необязательно, дата добавления `ГГГГ-ММ-ДД`.
- `images`: необязательно, до 4 прямых ссылок на картинки: первая — обложка, остальные — скриншоты.
- `models`: необязательно, для каких моделей ИИ: `["Claude", "Gemini"]`.
- `uncensored`: необязательно, `true` — без цензуры, `false` — с цензурой.
- `language`: необязательно, `en` — английский, `ru` — русский, `th` — тайский, `zh` — китайский. Пустое значение означает, что язык не указан.
- `translated`: необязательно, `true` — с переводом, `false` — без перевода. Отсутствие значения или `null` означает «Не указано», а не «Без перевода». Старые записи можно дополнить через «Изменить» в админке.
- `regex`: необязательно, сколько регексов внутри пресета (они лежат в самом пресете, в `extensions.regex_scripts`).
- `hash`, `size`: отпечаток файла, по нему приложение видит, что файл уже установлен. Ставятся при публикации из приложения.

Поле `submit` в корне файла — ссылка, куда присылать предложения (например `https://t.me/ник`).

При установке материал скачивается в SillyTavern. Уже существующие файлы не перезаписываются: новый получит свободное имя; расширение — отдельную папку.
